B2. Tạo mới Process Taget 
 + Trên menu Agreements chọn đến Process Taget 

PAGE 4
 
Màn hình chi tiết Process Taget 
 + Điền các thông tin cần thiết bao gồm 
- Service Level Taget ID : Mã ID của Process Taget 
- Agreeement ID : Mã ID của Agreement mà Process Taget gọi đến 
- Name : Tên của Process Taget 
- Condition : Điều kiện để chạy Process Taget 
- Service Level Category : Loại service level cam kết (OLA hoặc SLA) 
- Service Area : Module mà Process Taget được gọi đến 
- Initial State : Phase bắt đầu 
- Final State : Phasce kết thúc 
- Duration type : Dạng tính toán ( có thể chọn là Interval: điền cụ thể 
thời gian cam kết dịch vụ , Duration in record : tính toán dựa trên một 
biến được cấu hình trên bản ghi) 
- Schedule Value : giá trị của schedule mà người quản trị muốn 
process taget chạy trên hệ thống 
- Time zone : điền thông tin chọn là thời gian trên service ITSM được 
cài đặt 
- Alert : Thông báo của Process taget , sẽ được hướng dẫn trong phần 
công cụ alert  
- Suspend processing : trường hợp mà process tạm dừng
